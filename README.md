# Single-Page CV

A single-page resume built with **semantic HTML only**, as a practice project from [roadmap.sh](https://roadmap.sh/).

**Project URL:** https://roadmap.sh/projects/single-page-cv

## Goal

Practice structuring an HTML document using semantic tags, without CSS or JavaScript.

## Contents

The CV includes the following sections:

- **Header:** name, job title, and contact information
- **Skills:** technical skills
- **Education:** academic background
- **Experience:** work experience
- **Across the Internet:** profile links (LinkedIn, GitHub)

## What I practiced

- HTML5 document structure (`<!DOCTYPE>`, `<head>`, `<body>`)
- Semantic tags: `<header>`, `<main>`, `<section>`, `<article>`, `<address>`
- Heading hierarchy (`<h1>`–`<h3>`), lists, and links
- SEO and Open Graph metadata (`description`, `author`, `og:title`, etc.)
